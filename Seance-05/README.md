# Séance 5 - Bases juridiques en droit français d'un questionnaire

## Objectifs

- Comprendre la différence juridique entre enquête auto-administrée et enquête administrée par un enquêteur

- Comprendre ce qui est autorisé dans les questions d’un questionnaire scientifique ou non

- Comprendre ce qui est interdit dans les questions d’un questionnaire scientifique ou non

- Comprendre comment garantir la sécurité juridique d’un questionnaire

    1. La collecte de données à caractère personnel

    2. La délimitation des données collectées

    3. Les données sensibles
