# Séance 1 - Méthodes statistiques quantitatives en géographie

## Objectifs

- Comprendre les bases mathématiques des statistiques inférentielles

- Comprendre l’intérêt d’un échantillon

- Être capable de définir les différents types d’échantillon

- Construire un échantillon

- Comprendre l’intérêt de quantifier un phénomène socio-spatial

## Plan de la séance

Introduction générale

1. L’échantillonnage. Échantillonnage représentatif ou échantillonnage non représentatif

2. Les méthodes d’échantillonnage

    1. Les méthodes aléatoires

    2. Les méthodes non aléatoires

    3. Méthodes d’échantillonnage « Monte Carlo »

    4. Conclusion : construire un intervalle de fluctuation

3. La valeur de l’objectivité de la quantification

    1. Quantification descriptive : dénombrer

    2. Quantification explicative : objectiver

Conclusion générale

Exercice du semestre
