# Séance 7 - L'enquête de terrain dans et autour du site de Clignancourt - Recueil des données par une enquête administrée par un enquêteur

## Objectifs

- Être confronté au réalité du terrain lors de la réalisation d'une enquête par questionnaire administrée par un enquêteur

- Recueillir le plus sérieusement possible les données dans un temps limité

- Travailler en groupe afin d'être évalué par ses partenaires sur la manière de conduire l'enquête

## Consignes

Pendant 1h30, par groupes de 2 ou 3 étudiants, vous allez utiliser le questionnaire produit pour interviewer en face-à-face sur le terrain des passants, souvent très pressés. Un étudiant parmi le groupe interrogera le passant. Les autres membres du groupe évalueront sa prestation. Ses retours sont dans le but d'améliorer l'interview suivante opérée par un autre étudiant. L'évaluation entre vous est informelle, mais, si vous voulez obtenir une bonne collecte, elle est nécessaire.
