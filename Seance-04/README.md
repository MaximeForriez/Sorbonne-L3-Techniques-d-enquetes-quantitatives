# Séance 4 - Rédaction des questions

## Objectifs

- Comprendre comment motiver l’enquêté à répondre au questionnaire

- Comprendre les types de questions et leur utilité

- Comprendre comment formuler une question écrite dans un questionnaire

- Comprendre comment faciliter la réponse aux questions par les enquêtés

- Connaître toutes les règles d’écriture d’un questionnaire

- Comprendre comment tester son questionnaire

## Plan de la séance

Introduction générale

1. Les enjeux de la formulation des questions

2. Les types de question

    1. Les questions fermées et les questions ouvertes

    2. Les questions de fait et les questions d’opinion

    3. Les questions de comportements

    4. Les questions d’intention ou d’anticipation

    5. Les questions de connaissance

    6. Les renseignements signalétiques

3. Les principes généraux concernant la formulation des questions

    1. Les questions directes ou les questions indirectes

    2. L’accessibilité des questions

    3. La neutralité des questions

    4. La présentation du questionnaire

4. Les règles de rédaction des questions

    1. Les règles pour lutter contre l’effet d’imposition d’une problématique

    2. Les règles pour favoriser l’expression personnelle

    3. Les règles pour éviter les erreurs techniques

5. Le test du questionnaire

Conclusion générale
